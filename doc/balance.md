# 每面平面计数规则的平衡校验

本工具仅用于校验原有每面平面计数规则的默认 **30% 雷密度**，不是自动选难度器。`recommendedMines(side)` 始终按 `Math.round(side ** 3 * 0.3)` 计算，并保留最少 1 雷、最多总格数减 1 的边界。

## 规则与可见性

每个面的数字统计该面所在平面内的 8 个邻格。某面为零会自动展开对应邻格，六面全零的方块消失；和弦按被点面的平面比较旗数。

- **open**：所有已揭示格的六面数字均可用，对应间距 ≥115%。
- **closed**：仅面方向的轴邻格越界或已揭示时，该面的数字可用，对应默认 100% 间距。旗子、问号与隐藏格不使邻面可见；不模拟剥层。
- 可见性使用 `logic.js` 的纯函数 `closedFaceMask(board, i)`；`scene.js` 共用它，并保留场景层的 openView 和剥层分支。测试覆盖面方向、边界、格子状态、多个阶数和剥层，确保与原场景判定一致。
- 不额外模拟相机朝向、掠射角淡出、射线遮挡、鼠标可达性或人的记忆；允许旋转查看符合掩码的面，也允许点击任意推理或猜测选中的未知格。结果是规则层校验，不等于真实玩家的胜率。
- 自动展开直接使用 `Board.reveal`，即使零面不可见也会按游戏规则展开。求解器本身不读取遮挡面的数字。

## 求解器与统计口径

只使用玩家可知的格子状态、已揭示且可见的面数字及关联格，不读雷位、未揭示数字或总邻域计数。

1. 单约束：扣除已推断并插旗的雷后，剩余雷数为 0 判全安全，等于未知格数判全雷。
2. 单约束完全无法推进时，才进行子集推理：A⊆B 时计算 B\A 与雷数差，差集全安全或全雷时推进。不能立即判定的中间约束不保留。

每次推进后重新收集约束，直到通关或卡住。不使用总雷数约束、概率选点、回溯或全局 SAT。卡住时从未揭示且未插旗的格子中均匀随机揭示一个，踩雷即败，不丢弃失败局。

- **子集步骤占比**：只有第二层能推进的迭代次数 / 全部有进展的逻辑迭代次数，跨局汇总。一次迭代可标记或揭示多格；首击、自动展开的单格及猜测不计逻辑步骤。
- **卡住时已开比例**：每次猜测前记录 `revealedCount / (total - mineTotal)`，对所有卡住事件求平均。分母为全部安全格；包括致败猜测前的状态，多次卡住分别计入。无事件记 `—`，不是 0%。这是条件均值，不是每局首次卡住进度，可能受幸存局多次猜测影响。
- **无猜通关率**：零猜且获胜的局数 / 全部局数，首击不计猜测。
- 平均猜次数包含全部胜败局及致败的猜测；胜率包含猜测后获胜。

无猜通关率使用 Wilson 95% 置信区间。令 p 为成功比例、n 为局数、z=1.959963984540054：

```text
center = (p + z²/(2n)) / (1 + z²/n)
half   = z × sqrt(p(1-p)/n + z²/(4n²)) / (1 + z²/n)
CI     = [center - half, center + half]
```

这是每组比例的区间，不是组间差值检验。逻辑步骤与卡住事件在同一局内相关，不对这些事件比例套用独立二项样本的 Wilson 区间。

## 参数与复现

```sh
cd web
node scripts/balance.mjs
```

固定扫描 25/30/35/40/45% 密度、5/7 阶和 open/closed 两种可见性，不包含规则维度或自动推荐逻辑。5 阶每组 300 局，7 阶每组 150 局，共 20 组、4,500 局。

固定种子为 `20261112 + side * 100000 + percent * 1000 + trial`。首击在中心附近 3×3×3 均匀随机选择，闭 26 邻域排雷；本扫描不会触发首击安全区退化。布雷流先生成首击再布雷；猜测使用 `seed ^ 0x9e3779b9` 的独立随机流。同阶数、密度、局号在两种可见性下共享首击和雷位。雷数按 `Math.round(side ** 3 * density)` 舍入。

## 默认 30% 的校验结论

closed 模式下，5 阶默认 38 雷的无猜通关率为 294/300=98.0% [95.7%,99.1%]，7 阶默认 103 雷为 147/150=98.0% [94.3%,99.3%]。卡住时已开比例分别为 98.85%、99.17%，说明此求解器在默认密度下通常能推进到残局。

更高密度显示出区分度：closed/5 阶从 30% 的 98.0% 无猜通关降至 45% 的 38.3%；closed/7 阶从 98.0% 降至 46.7%。与此同时，子集步骤占比提高、卡住进度下降。open 模式较容易，例如 5 阶 45% 的无猜率仍为 81.3%，说明拉开间距提供的面信息会影响求解表现。

这些结果用于确认默认 30% 在当前模型下具有较高可推理性，不证明人类玩家也能达到同样胜率。默认组仍接近指标饱和，且卡住事件仅有 6 次和 3 次；不能凭一局差异或条件均值的微小差异做难度排序。推荐密度保持 30%，工具不根据有限样本自动调整游戏设置。
